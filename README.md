# LEGO Education Portfolio

LEGO를 활용한 참여형 교육 철학과 프로그램을 소개하는 개인 홈페이지입니다.

## 구성
- `index.html` — 메인 페이지
- `styles.css` — 반응형 디자인
- `script.js` — 모바일 메뉴 및 스크롤 등장 효과
- `.nojekyll` — GitHub Pages 정적 배포 설정

## GitHub Pages 배포
GitHub 저장소의 **Settings → Pages**에서 배포 소스를 기본 브랜치의 `/ (root)`로 설정하면 됩니다.

예상 주소:
`https://bonghankhan.github.io/lego-education/`
